# Personal Portfolio Website

## Overview

This is a full-stack personal portfolio website built to showcase projects and skills.

## Features

* Responsive frontend using HTML, CSS, and JavaScript
* Backend developed with Node.js and Express.js
* MySQL database integration for storing project information
* Dynamic project retrieval through API endpoints
* Deployed using Vercel

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MySQL
* Git
* GitHub
* Vercel

## How to Run Locally

1. Install dependencies:

```
npm install
```

2. Start the server:

```
node server.js
```

3. Open:

```
http://localhost:3000
```
